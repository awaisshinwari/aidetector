# Assignment Originality & Improvement Checker

Streamlit app that checks if an assignment is copy-pasted or originally written using Gemini 2.0 Flash.

### Features
- Supports PDF, DOCX, TXT, JPG/PNG (handwritten too)
- Verdict: Original vs Copy-Pasted with confidence %
- Quality Score / 10
- Grammar, Structure, Depth improvements
- Converts assignment into resume bullet points
